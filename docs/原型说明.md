# 家庭健康跟踪助手原型说明

本目录配套的静态原型位于 `prototype/index.html`，可直接用浏览器打开。它不是最终小程序代码，而是用于确认信息架构、视觉风格和老人友好操作路径的前端样稿。

## 原型包含页面

- 今天：家庭状态、可见成员切换、快捷记录入口、今日待办。
- 记录：指标录入面板、趋势卡片、最近记录。
- 饮食：拍照分析入口、营养结构、建议文案。
- 家庭：6 位成员权限展示、提醒、档案入口。

## 设计方向

- 字号偏大，按钮偏高，减少密集表格。
- 用温和的绿色、蓝色和珊瑚色区分健康、记录和提醒状态。
- 首页强调“今天做什么”，避免老人进入复杂菜单。
- 数据提示使用“偏高、注意、平稳”等词，不输出诊断结论。

## 健康提示边界

所有页面的建议只用于家庭健康管理参考，不替代医生诊断。涉及用药调整、治疗方案、长期异常指标时，应提示咨询医生或药师。
