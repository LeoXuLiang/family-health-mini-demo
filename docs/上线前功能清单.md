# 上线前功能清单

## 必须完成

- 微信登录：获取 openId，通过云函数创建或读取用户。
- 身份绑定：用户加入家庭后绑定到 6 位成员之一。
- 家庭邀请：管理员生成一次性邀请码或小程序分享卡片。
- 后端权限：云函数校验成员可见范围，不能只依赖前端隐藏。
- 云数据库：保存成员档案、指标记录、饮食记录、提醒、就医和用药记录。
- 隐私保护：配置微信隐私保护指引，并在首次使用时解释健康数据和照片用途。
- 数据管理：提供删除记录、删除照片、退出家庭、撤回授权入口。
- 健康边界：建议类文案只做健康管理参考，不输出诊断或用药调整建议。

## 建议首版完成

- 指标趋势：7 天、30 天、90 天切换。
- 异常提醒：按成员设置关注范围，只做提醒不做诊断。
- 餐食分析：图片上传到云函数，结合成员档案和近期指标给饮食建议。
- 人工修正：用户可修正菜名、份量和餐次。
- 订阅消息：每日血压、餐后血糖、复诊和用药记录提醒。
- 成员详情：基本信息、慢病标签、过敏史、常用药备注、医生关注事项。
- 家庭周报：自动汇总一周记录和需要关注的变化。

## 发布前检查

- 小程序 AppID 已写入 `src/manifest.json`。
- 微信公众平台已配置服务类目、头像、简介和隐私保护指引。
- 所有后端接口使用 HTTPS 或微信云开发。
- 小程序端不暴露 AI API Key。
- 餐食照片和检查报告支持删除。
- 用药页面明确提示：涉及用药调整请咨询医生或药师。
